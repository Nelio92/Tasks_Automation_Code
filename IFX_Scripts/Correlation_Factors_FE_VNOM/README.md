# Correlation_Factors_FE_VNOM

This folder contains FE correlation-factor source workbooks, generated VNOM artifacts, and corner-specific text exports for TXLO and TXPA.

## Source workbooks

- `CV_ATE_Correlation_TXLO_Power_FE.xlsx`
- `CV_ATE_Correlation_TXPA_Power_FE.xlsx`

The `Correlation_Factors` sheet in each workbook stores:

- `Corr_Factors_VMIN`
- `Corr_Factors_VMAX`
- `Corr_Factors_VNOM` generated by `generate_vnom_correlation_factors.py`

VNOM is computed by linear interpolation in supply between 95% and 105%:

`CF_VNOM = CF_VMIN + ((1.00 - 0.95) / (1.05 - 0.95)) * (CF_VMAX - CF_VMIN)`

This simplifies to:

`CF_VNOM = 0.5 * (CF_VMIN + CF_VMAX)`

## Text files

The generator writes text files for all three corners:

- `VMIN`
- `VNOM`
- `VMAX`

Temperature labels used in filenames:

- `Cold` = `-40 C`
- `Ambient` = `25 C`
- `Hot` = `135 C`

### TXLO layout

Filename pattern:

- `Corr_Factors_FE_TXLO_<CORNER>_81_77_76_GHz_<TEMP>.txt`

Each TXLO file contains 36 values in this order:

1. `Data [1] ... Data [12]` = `81 GHz`
2. `Data [13] ... Data [24]` = `77 GHz`
3. `Data [25] ... Data [36]` = `76 GHz`

Within each frequency block, the IDAC order is:

- `10, 14, 18, 22, 27, 34, 42, 51, 63, 78, 96, 112`

Formatting:

- TXLO values are written with `3` decimal places.

### TXPA layout

Filename pattern:

- `Corr_Factors_FE_TXPA_<CORNER>_<FREQ>GHz_<TEMP>.txt`

Each TXPA file contains 21 values in this order:

1. `Data [1] ... Data [13]` = LUT values `12, 22, 36, 48, 69, 86, 114, 130, 148, 170, 182, 195, 244`
2. `Data [14] ... Data [21]` = LUT `255` for channels `TX1 ... TX8`

Formatting:

- TXPA values are written with `9` decimal places.

Frequencies generated for TXPA:

- `76 GHz`
- `77 GHz`
- `81 GHz`
