# Test Data Reviewer

Test Data Reviewer is a packaged analysis tool for reviewing production test data and generating ready-to-use review artifacts for Test Engineering.

## Supported Input Data

The tool can analyze:

- flat production CSV files
- STDF and EFF source files when pre-conversion is enabled in the configuration

Supported source formats include standard and compressed variants used in the production flow.

## Main Outputs

Typical outputs generated by the tool:

- `Test_Data_Reviewer_Report.xlsx`
- `cdf_plots/...`
- `Correlation_Report.xlsx` when enabled
- `Artifacts/...` when STDF conversion is enabled

## Getting Started

1. Open a YAML configuration file from the `configs` folder.
2. Check the following fields:
   - `input_folder`
   - `modules`
   - `convert_stdf_before_analysis`
3. Run the tool from PowerShell.

Example:

```powershell
.\TestDataReviewer.exe --config .\configs\config.yaml
```

## Recommended First Check

Run a dry-run before processing a new dataset:

```powershell
.\TestDataReviewer.exe --config .\configs\config.yaml --dry-run
```

This helps confirm:

- the selected config is correct
- the input path is valid
- the derived output folder under the input path is valid
- STDF conversion is enabled or disabled as expected

## Typical Usage

### Analyze CSV Files Directly

- place CSV files in the configured input folder
- set `convert_stdf_before_analysis: false`
- run the executable

### Analyze STDF or EFF Files Directly

- place source files in the configured input folder
- set `convert_stdf_before_analysis: true`
- run the executable

### Analyze One Source File

- set `stdf_single_file` in the YAML configuration
- run the executable

## Need Help?

If the tool does not run as expected:

1. Run a dry-run first.
2. Verify that the input path is correct.
3. Confirm that the tool can create the `Outputs` folder under the input path.
4. Confirm that the input files match the selected mode.
5. Make sure the Excel output file is not already open.

For full operating details, see `Test_Data_Reviewer_User_Guide.md`.
